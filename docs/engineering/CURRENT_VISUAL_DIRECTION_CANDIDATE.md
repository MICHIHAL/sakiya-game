## Pixel and motion grammar

- Art and interface share one coarse 8-bit-era visual language: a 256×144-to-320×180 logical-density impression, 16–20-color-like compact ramps, hard pixel edges, chamfered or square frames, large crisp offset shadows, and no soft modern blur.
- UI remains real HTML/CSS. Pixel treatment is created with borders, layered shadows, repeating patterns, and step-timed states rather than rasterizing controls or text.
- Motion uses short `steps()` loops: two-to-four-frame idle bob, blink, monitor pulse, window lights, heart/spark pixels, arrival/chime burst, pressed-button one-pixel nudge, and number ticks.
- Motion communicates state. It does not continuously shake the whole screen or obstruct reading.
- Reduced Motion freezes each loop on a meaningful readable frame and keeps changes visible through outline, color, copy, and before/after state.
